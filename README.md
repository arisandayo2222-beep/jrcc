# JRC スライドメーカー

イベント(送る会・交流会など)の進行用スライドを、ブラウザだけで作れるツール。

## 使い方
1. `index.html` をブラウザで開く(GitHub Pages でも、ファイルを直接開いても動く)
2. **イベント**ページでタイトル・日付・テーマを入力
3. **スタイル**ページで見た目を選ぶ(自作スタイルも追加可)
4. **プログラム**ページで項目名と所要時間(5分刻み)を入力
   - 「日の区切り」を入れると複数日に分けられ、日ごとに開始時刻も設定できる(空なら全体の開始時刻)
5. **内容**ページで各項目のスライドに載せる文を入力(空でもOK)
6. 「▶ スライドを表示」で全画面表示、「📤 書き出し」で保存

## できること
- 開始時刻と所要時間から各項目の時刻を自動計算
- プログラム一覧(1ページ5項目)と、各項目をハイライトしたスライドを自動生成
- 漢字に自動でふりがな(タップで読みを修正、修正内容は辞書に保存)
- 書き出し:PDF / 画像(ZIP)/ 画像PPTX / 編集できるPPTX

## 仕組み
- `index.html` 1ファイルに HTML・CSS・JavaScript をまとめている。サーバー不要
- 外部ライブラリは CDN から読み込み(html2canvas, jsPDF, JSZip, PptxGenJS)。書き出しにはネット接続が必要
- 入力内容・ふりがな辞書・自作スタイルはブラウザの localStorage に自動保存。別の端末とは共有されず、ブラウザのデータ削除で消える
- AI や外部 API は使っていない。入力データは外部に送信しない
